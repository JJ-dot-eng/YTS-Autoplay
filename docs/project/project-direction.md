# YTS Autoplay 프로젝트 방향

## 제품 목적

YTS Autoplay는 YouTube Shorts 영상이 끝났을 때 사용자가 직접 스크롤하지 않아도 다음 Shorts로 안전하게 이동시키는 최소 권한의 Chrome 확장프로그램이다.

## 0.6.2 안정화 방향

- 자동 넘김은 실제 영상 종료, 종료 직전, 자연 반복처럼 종료를 의미하는 신호에만 반응한다.
- 사용자의 수동 탐색, 같은 영상의 DOM 재생성, 느린 YouTube SPA 전환을 종료나 이동 성공으로 오인하지 않는다.
- 이동 성공은 URL의 Short ID 변경으로 확인하고, 실패 재시도에는 충분한 대기 시간과 횟수 제한을 둔다.
- 저장된 켜기/끄기 설정을 확인하기 전에는 자동 넘김을 시작하지 않는다.
- DOM 감시와 고빈도 폴링은 기능이 켜진 Shorts 페이지에서만 실행한다.
- YouTube DOM에 의존하는 순수 판정 로직은 Node 내장 테스트로 회귀 검증할 수 있게 분리한다.
- popup은 저장 실패를 사용자에게 알리고 스위치 이름과 상태를 보조기술이 구분해 읽을 수 있게 한다.
- Manifest와 패키지 버전, ZIP 구성과 원본 일치 여부를 릴리스 과정에서 자동 검증한다.

## 범위 원칙

- 외부 서버, 분석 도구, 사용자 데이터 수집은 추가하지 않는다.
- 호스트 범위는 `https://www.youtube.com/*` 밖으로 넓히지 않는다.
- 일반 YouTube 페이지에서는 경로 이동 감지를 위한 가벼운 이벤트 리스너만 유지한다.
- 실제 Chrome 검증은 URL이 다른 `/shorts/...`로 바뀌고 새 영상이 재생되는 것까지 확인한다.
